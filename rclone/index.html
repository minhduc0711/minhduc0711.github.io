rclone

Public Home Page

rclone is the name of a personal Google OAuth client used with the rclone command-line tool. Its purpose is to let its owner and authorized test users create a custom Google Drive client ID and secret for use with rclone.

This is not the official rclone website and is not affiliated with, endorsed by, or maintained by the rclone project.

Application name: rclone. This page is public and does not require a login.

Purpose

What this OAuth client is for

Custom rclone credentials

The client is used to create and configure a personal Google Drive OAuth client ID and secret. You create the credentials in your own Google Cloud project by following the official rclone instructions, then use them with rclone on your own device.

Personal use only

The client is intended for its owner and a small number of authorized test users. This website only provides the public home page and privacy policy that Google requires. It does not create client IDs automatically or operate rclone.

Privacy

What this website does with data

This is a static informational website. It does not sign users in and does not receive Google account data, Google Drive files, OAuth tokens, or client secrets. Your credentials are stored in your local rclone configuration, and Google authorization happens directly between your device and Google.
